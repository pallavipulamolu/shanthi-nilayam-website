# Photograph slots

The site never shows stock or invented photographs. Every image position is a
named "slot" (see `src/data/photos.ts`). Until a file exists the slot shows a
clearly labelled placeholder.

To use a real, consented photograph: drop a file named after the slot id into
this folder (jpg, jpeg, png, webp or avif). Example: `hero-main.jpg`.
No code changes needed. Only add photographs the centre has approved, and do
not identify residents without consent.
